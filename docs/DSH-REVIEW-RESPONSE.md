# DSH 兼容性评测核对与处理

日期：2026-10-29。原评测：源码项目 `docs/COMPATIBILITY.md`，针对 alpha.2 源码与已安装 alpha.1 的静态评测。保留原文，本记录补充 alpha.3 的核对结果。

| 评测意见 | 核对与处理 |
| --- | --- |
| 桌面仍安装 alpha.1，源码更新不生效 | 已只读核实桌面 profile 的 dependency 仍为 alpha.1 的 `link:`，bundles 中只有一个对应条目。新版交付说明加入替换旧版、确认版本、不要双挂载的步骤。本次未修改日常桌面 profile。 |
| 双挂载可能重复注册路由 | 同意。保留宿主原有重复路由拒绝机制，不绕过。更新说明要求只保留一个条目，不能叠加旧 link 和新包。 |
| 精确锁定版本会限制宿主升级 | 属于已知取舍。继续锁 0.2.1-rc.3：只对验证过的版本作承诺。不能只为安装成功放宽兼容范围；后续逐版本测试再调整。alpha.3 新增同版本 dsh-session peer。 |
| 使用的主题变量不存在，始终回退 | 已核对官方主题包采用 alias 系列变量；原变量未接上。现版保持自有浅色/深色配色，视觉跟随和玻璃效果暂不在本轮功能变更中加入，不能宣称跟随壁纸主题。 |
| 与现有插件组合未实机验证 | 同意。当前证据仍来自隔离 Web profile，不能把没有发现静态冲突写成已兼容。桌面共存、长时间运行与强退保留为待验证。 |

alpha.3 已改变原评测中的“只读标题”边界：用户点击生成交接包时，还会通过只读句柄读取所选会话的已持久化消息。不会后台遍历会话。用户点击草稿按钮时，可由宿主创建或复用空会话并填入草稿；插件不发送、不调用模型。只有用户在 DSH 中发送后，材料才进入所选模型。Host 新增 POST `/api/task-shelf/handoff`，继承同一宿主认证。

本轮新增 6 项交接单元测试、6 项实际界面检查，并回归原有 13 项界面流程。真实生成模型摘要的质量、其他插件拥有消息投影的会话、用户日常桌面共存仍未验证。缺少所需消息投影时明确拒绝导出，不尝试猜测还原内容。
