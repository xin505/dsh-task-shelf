# DSH 版本维护

仓库默认分支包含每日检查上游 GitHub Release 的工作流，也支持手动运行。脚本仅比较正式版和 rc，忽略 alpha；发现比已验证版本更新的发行版时将检查标为失败，以便维护者查看。GitHub 通知取决于仓库 Actions 和个人通知设置；该检查不会自动修改插件或安装宿主。

新版本发现后，用官方精确版本在独立 DSH_HOME 和合成工作区运行自动测试、浏览器资料夹回归、跨工作区交接和压缩检查；记录宿主来源、运行时间和结果。通过后同时调整 engines.dsh 和所有官方 peerDependencies 的显式版本，更新版本号和验证记录，重新构建、测试及打包。需要用户或维护者审核、推送并发布。测试不通过时保留当前兼容范围，修复后重测。不可推断未测试版本可用，也不保证未来版本一定能自动适配。

计划任务仅在 GitHub 默认分支生效；该工作流当前只是本地改动，推送并合入默认分支后才会运行。
